To connect another browser, install the extension from Aegis → Settings → Browser extension, then enter the six-digit code in its popup. Pairing tokens are stored as hashes on your machine and can be revoked at any time.

Auto-save submitted logins When a login form is submitted, Aegis can create or update the matching item.

Auto-save only runs while Aegis is unlocked. The extension sends the submitted username and password to the loopback bridge; Aegis stores it in the encrypted vault on this computer.

How matching worksDomain-first, no cloud lookup.
  • 1. The extension asks the desktop app for logins whose saved URL matches the active site.
  • 2. Only after you press Fill does the app return that one username and password.
  • 3. The browser receives the values, writes them into the form, and never sees the rest of the vault.
  • 4. Auto-save is optional and can be turned off here or in the popup.
